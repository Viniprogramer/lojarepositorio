# MotoForge Parts Pro — E-commerce de Portfólio

Projeto demonstrativo de alto nível para portfólio freelancer, inspirado em padrões de e-commerce de peças para motocicletas, mas com identidade visual e arquitetura próprias.

## Stack
- React 18
- Vite
- React Router
- CSS responsivo
- LocalStorage
- Sem backend e sem gateway real

## Rodar
```bash
npm install
npm run dev
```
Abra a URL do Vite, normalmente `http://localhost:5173`.

## Funcionalidades
- Home premium
- Catálogo com busca
- Filtros por categoria, marca, moto e preço
- Ordenação
- Rotas de categorias
- Página individual de produto
- Galeria de imagens
- Especificações técnicas
- Produtos relacionados
- Wishlist persistida
- Carrinho persistido
- Drawer de carrinho
- Checkout em duas etapas
- Pedido simulado
- Login/cadastro simulado
- Área do cliente
- Histórico de pedidos
- Seções sobre/contato
- FAQ/reviews/newsletter
- Responsividade
- 404
- Dados e estado simulados no LocalStorage

## Observação de portfólio
O checkout, autenticação, pedidos e dados são propositalmente simulados. Não há processamento financeiro ou backend.
